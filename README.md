# 📱 Мосбиржа Сигналы — Android APK

## 🔧 **Как получить APK за 2 шага:**

### **Шаг 1: Скачать архив**

Скачай архив и распакуй: **`moex_github_build.zip`**

Внутри:
- `moex_signals_app.py` — приложение
- `buildozer.spec` — настройки сборки
- `.github/workflows/build.yml` — автомат сборки

### **Шаг 2: Загрузить на GitHub**

1. Зайди на **[github.com](https://github.com)** и войди
2. Нажми зелёную кнопку **«New»** (создать репозиторий)
3. Назови как хочешь, например `moex-signals`
4. Поставь галочку **«Public»** или **«Private»** — неважно
5. Нажми **«Create repository»**

6. Теперь **загрузи файлы**:
   - Нажми **«Add file» → «Upload files»**
   - Перетащи туда все файлы из архива (все сразу)
   - Нажми **«Commit changes»**

7. GitHub **сам начнёт сборку** ✅

### **Шаг 3: Скачать APK**

1. Зайди в свой репозиторий на GitHub
2. Нажми вкладку **«Actions»**
3. Увидишь жёлтый кружок — идёт сборка (около 30 минут)
4. Когда станет зелёная галочка ✅ — нажми на неё
5. Внизу увидишь **«moex-signals-apk»** — нажми и скачай APK
6. Отправь APK себе в Telegram и установи на телефон

> ⚠️ При установке Android может ругаться «неизвестный источник» — разреши установку, это твой собственный APK.

---

## 🔄 **Как обновить приложение:**

1. Отредактируй `moex_signals_app.py` (поменяй логику, добавь тикеры и т.п.)
2. Сохрани изменения в GitHub (Commit)
3. GitHub Actions автоматически соберёт новый APK
4. Скачай готовый APK из Actions

---

## ❓ **Проблемы:**

- **Сборка упала** — напиши мне текст ошибки из лога Actions
- **APK не устанавливается** — попробуй включить «Установка из неизвестных источников»
- **Не работают уведомления** — в настройках телефона разреши уведомления для приложения
